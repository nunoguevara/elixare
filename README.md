# elixare
An extensible and lightweight boilerplate generator that also can be used
out-of-the-box for convenient and control.

## Features
- Lightweight
- Blazing fast
- Minimalist
- Extension support through source code editing

## Installation
For installation, you'd need:
- Rust compiler
- cargo

To install it, you can use the following methods below:

### Cargo
```shell
cargo install elixare
```

### Building from source
```shell
git clone --depth 1 https://github.com/nunoguevara/elixare.git
cd elixare
cargo install --path
```
